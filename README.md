# Sales Forecasting Project

This repository contains a sales forecasting notebook built with Python and time-series methods.

## Contents

- `sales_forecast.ipynb` — Jupyter notebook that generates historical sales data, performs data cleaning, engineers time-based features, trains forecasting models, evaluates accuracy, and visualizes future demand.

## Usage

1. Open `sales_forecast.ipynb` in Jupyter or VS Code.
2. Run all cells to generate the synthetic sales dataset and forecast results.
3. Review the model evaluation metrics and forecast charts for business insights.

## Notes

- The notebook uses synthetic weekly sales data for demonstration.
- Add your own historical sales data if you want to replace the synthetic dataset.
